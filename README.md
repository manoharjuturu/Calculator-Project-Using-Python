🧮 Calculator App

A simple Python Calculator App that performs basic mathematical operations using functions and user input.

📌 Features

This calculator supports the following operations:

➕ Addition
➖ Subtraction
✖️ Multiplication
➗ Division
🔢 Power

It also handles division by zero and displays an appropriate message.

🛠️ Technologies Used
Python 3
Functions
Conditional statements (if, elif, else)
User input using input()

💻 How to Use

When you run the program, you will see:

---calculator App---
1.Addition
2.substraction
3.multiplication
4.division
5.power

Select an option and enter two numbers.

Example
Select on option: 1
Enter The Number1: 10
Enter The Number2: 20
Result: 30

Division Example
Select on option: 4
Enter The Number1: 10
Enter The Number2: 2
Result: 5.0

Power Example
Select on option: 5
Enter The Number1: 2
Enter The Number2: 3
Result: 8

⚠️ Error Handling

The program checks whether the second number is 0 when performing division.

Select on option: 4
Enter The Number1: 10
Enter The Number2: 0
Result: cannot be division
